# Fungred（复刻版）

2022 年 Unity 项目《Fungred》的完整玩法复刻，用 Three.js 重写，无需 Unity。
原工程：`G:\Develop\Unity\PROJECTS\Fungred`；前五名英雄的数值、技能、AI 行为 1:1 移植自 3.6/3.7 源码，
后五名英雄、召唤战术牌和物品卡按 Illustrator 设计稿 `fungred3.0.ai`（2022-09-05）实装——当年画好了却没做进游戏。

## 启动

双击 `start.bat`（本地起 node 静态服务器，端口 8767，自动开浏览器）。线上版：myjs999.com/games/fungred/，电脑和手机都能玩。

## 玩法

- 双方各一座 150 HP 基地，摧毁对方基地获胜（原版 300，压缩对局时长）。
- 4 条战线，每条战线只能驻守 1 名英雄（改版规则；原版为 3 线 2 人可换位）。
- **召唤玉**：10 颗玉各绑定一名英雄，花召唤点召唤（召唤点每回合 +2，每 10 回合额外 +1）。
  英雄死后玉进入冷却（3 回合起步，死亡次数越多越久）、费用按原价累加，但**经验由玉保留**。
- 英雄每回合获得 1 点经验，等级 = 魔力上限，魔力每回合回满。
- 普攻伤害 = 攻击 − 防御（打不穿则无效）；对面战线有敌人时不能直击基地。
- **召唤战术牌**：双方各有 32 张牌库（12 种经济牌 + 4 种物品卡，每种两张）。开局 4 张，每回合摸 1 张，
  可打任意张，回合结束手牌上限 4（地产可提高）。标「持有」的牌放在手里持续生效。

## 结构

- `src/data.js` — 英雄 / 召唤玉 / 卡牌 / 百科数据
- `src/game.js` — 规则引擎（纯逻辑，向 fxQueue 推表现事件）
- `src/main.js` — Three.js 场景 + 动画队列 + UI
- `src/audio.js` — WebAudio 合成音效
- `_ref/`（不进 git）— 2026-09-30 的资料包：Illustrator 原稿、设定稿、Unity 工程

调试钩子：控制台 `window.__g`（状态与操作）、`window.__shot('name')`（截帧存 `_shots/`）。
