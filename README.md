# Fungred（复刻版）

2022 年 Unity 项目《Fungred》的完整玩法复刻，用 Three.js 重写，无需 Unity。
原工程：`G:\Develop\Unity\PROJECTS\Fungred`（数值、技能、AI 行为均 1:1 移植自 3.6/3.7 源码）。

## 启动

双击 `start.bat`（本地起 node 静态服务器，端口 8767，自动开浏览器）。

## 玩法

- 双方各一座 150 HP 基地，摧毁对方基地获胜（原版 300，压缩对局时长）。
- 4 条战线，每条战线只能驻守 1 名英雄（改版规则；原版为 3 线 2 人可换位）。
- **召唤玉**：5 颗玉各绑定一名英雄，花召唤点召唤（召唤点每回合 +2，每 10 回合额外 +1）。
  英雄死后玉进入冷却（3 回合起步，死亡次数越多越久）、费用按原价累加，但**经验由玉保留**。
- 英雄每回合获得 1 点经验，等级 = 魔力上限，魔力每回合回满。
- 普攻伤害 = 攻击 − 防御（打不穿则无效）；对面战线有敌人时不能直击基地。
- 敌方 AI：狂造利科特并倾泻技能连招（原版行为）。

保留了原版的若干"特性"：不渝之心不消耗使用次数、魔力友谊先扣费再转移、
一隅天涯的守护标记整回合有效等。

**角色百科**：顶栏「百科」按钮打开全屏图鉴——世界观（拉文德市/天启轮回）+ 十位英雄的
出身传记、数值技能与语录。前五人取自 D:\Raitingu 正典设定文档，后五人按同一世界观补写。
英雄的登场/阵亡台词会在战斗中实际浮现；头顶标签显示 HP/MP/攻/防（攻防受增减益时变色）。

敌方 AI v2：按局势选线（优先堵高攻）、按对位选人（高攻上坦克、残血上刺客、
空线上攻城）、每回合最多召两人，每个英雄有自己的技能逻辑；利科特保留原版连招。

## 结构

- `src/data.js` — 英雄/召唤玉数据
- `src/game.js` — 规则引擎（纯逻辑，向 fxQueue 推表现事件）
- `src/main.js` — Three.js 场景 + 动画队列 + UI
- `src/audio.js` — WebAudio 合成音效（零素材：命中/召唤/技能各系音色/基地钟声/胜负和弦）

打击反馈：受击闪白+弹缩、基地受击相机震动、击杀顿帧+全屏白闪（`prefers-reduced-motion` 下关闭）。
- 调试钩子：控制台 `window.__g`（状态与操作）、`window.__shot('name')`（截帧存 `_shots/`）
